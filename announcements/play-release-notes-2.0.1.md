# Google Play release notes, 2.0.1

Paste the block below into the release's **Release notes** box in Play Console (GOOGLE-PLAY.md,
section 10). Play allows 500 characters per language. The tag must match a language the store
listing has (`en-GB`, English (United Kingdom)).

2.0.0 hasn't been on Google Play, so if 2.0.1 is uwuHere's first release there, use the 2.0.0
notes (`play-release-notes-2.0.0.md`) instead: they say what the app is. These are for when 2.0.0
has already gone out on Play.

```text
<en-GB>
• The app opens again: 2.0.0 could close as soon as it started
• Notification switches stay on after you allow notifications
• The Updates page and Notifications agree on new-version alerts
• The tour's Skip button is easier to see
</en-GB>
```
