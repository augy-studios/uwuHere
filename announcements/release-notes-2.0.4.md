uwuHere's code has been tidied up to read more plainly, on every device, so fixes and new features come more easily. Nothing changes in how the app works, and your events and settings stay as they were. The Android app comes up to 2.0.4 too, so every device now has the same version.

## Download

| Device | File |
| --- | --- |
| Android 7.0 or newer | `uwuhere-2.0.4.apk` |
| Windows 10 or 11 (x64 or Arm) | `uwuhere-2.0.4-setup.exe` (or the `.msi`, for installing on many computers at once) |
| Mac with Apple silicon (M1 and later) | `uwuhere-2.0.4-mac-arm64.dmg` |
| Mac with an Intel processor | `uwuhere-2.0.4-mac-x64.dmg` |
| Debian, Ubuntu, Mint (x64 or arm64) | `uwuhere-2.0.4-amd64.deb` or `uwuhere-2.0.4-arm64.deb` |
| Fedora, openSUSE | `uwuhere-2.0.4-x86_64.rpm` or `uwuhere-2.0.4-aarch64.rpm` |
| Any other Linux | `uwuhere-2.0.4-x86_64.AppImage` or `uwuhere-2.0.4-aarch64.AppImage` |

On an iPhone or any other device, use [here.uwuapps.org](https://here.uwuapps.org) in the browser. Attendees never need an app: the website checks them in.

## Installing

- **Android**: tap **Update** on the bar at the top, or the download-arrow button in the Edge Tray. From Google Play, Play updates it.
- **Windows, macOS, AppImage**: uwuHere offers **Restart to update** by itself. For the `.msi`, `.deb` and `.rpm`, install the new file over the old one.
- New to uwuHere? The steps for each device are on the [2.0.0 release](https://github.com/augy-studios/uwuHere/releases/tag/android-v2.0.0).

## What's changed

### Everywhere
- **Easier to look after**: the code behind the apps and the website has been rewritten to read more plainly, so fixes and new features come more easily. Nothing changes in how uwuHere works.

### Android app
- **The same version as the computers**: the Android app goes from 2.0.1 to 2.0.4. 2.0.2 and 2.0.3 changed only the Windows, macOS and Linux apps.
