The Fluent 2 look's title bar on Windows is white again (dark grey in dark mode), not a strip of your accent colour. This release is for computers only: the Android app stays at 2.0.1.

## Download

| Device | File |
| --- | --- |
| Windows 10 or 11 (x64 or Arm) | `uwuhere-2.0.3-setup.exe` (or the `.msi`, for installing on many computers at once) |
| Mac with Apple silicon (M1 and later) | `uwuhere-2.0.3-mac-arm64.dmg` |
| Mac with an Intel processor | `uwuhere-2.0.3-mac-x64.dmg` |
| Debian, Ubuntu, Mint (x64 or arm64) | `uwuhere-2.0.3-amd64.deb` or `uwuhere-2.0.3-arm64.deb` |
| Fedora, openSUSE | `uwuhere-2.0.3-x86_64.rpm` or `uwuhere-2.0.3-aarch64.rpm` |
| Any other Linux | `uwuhere-2.0.3-x86_64.AppImage` or `uwuhere-2.0.3-aarch64.AppImage` |

On Android, `uwuhere-2.0.1.apk` is on the [2.0.1 release](https://github.com/augy-studios/uwuHere/releases/tag/android-v2.0.1). On an iPhone or any other device, use [here.uwuapps.org](https://here.uwuapps.org) in the browser. Attendees never need an app: the website checks them in.

## Installing

- **Windows, macOS, AppImage**: uwuHere offers **Restart to update** by itself. For the `.msi`, `.deb` and `.rpm`, install the new file over the old one.
- New to uwuHere? The steps for each device are on the [2.0.0 release](https://github.com/augy-studios/uwuHere/releases/tag/android-v2.0.0).

## What's fixed

### Windows app
- **Fluent 2's title bar**: with **Show accent colour on title bars and window borders** turned on in Windows' settings, a solid strip of the accent colour covered the top of the window, behind the search bar and the buttons. The title bar is now white, or Fluent's dark grey in dark mode, as Windows 11's own apps have it.
