✨UPDATE✨ uwuHere 2.0.0: the apps, rebuilt, and now on your computer too
here.uwuapps.org

Everywhere:
- Report a bug, with a screenshot of the whole page and a report ID to quote
- A short tour of each page the first time you open it
- A Privacy page that says what's kept and when it's deleted
- A new icon

Android app:
- Every screen built for Android: quick to open, offline from the first open
- Material You by default, with the UwU Apps look a switch away in Theme
- An Updates page with what's new in every version
- Notifications for check-ins, new versions and news, each its own switch
- Your events come across from 1.x by themselves
- No ads, no analytics

Windows, macOS and Linux apps (new):
- Host from a laptop: same wifi, location, the big QR code and the CSV
- Your events beside the page, and a command bar (Ctrl+K) to find any of them
- Your event as a desktop widget, and its count in the tray
- Check-in notifications while it runs

Already on the Android app? It updates itself.
